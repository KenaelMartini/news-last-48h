# Archived News and Market Report Pipeline

This repository contains an earlier working environment used to collect recent financial news, generate market summaries and produce recurring macro and session reports.

It includes source code, configuration files, generated reports, document-formatting utilities, local outputs and build artefacts created during development.

## Repository status

This project is no longer actively maintained.

The repository is kept as an archive of an earlier research and automation workflow. Its structure reflects an experimental development environment rather than a production-ready application.

Some files, reports, market assumptions and generated outputs are outdated. Build files, temporary outputs and duplicated documents are also retained as part of the historical project state.

For a cleaner and more current example of my work on financial data, macroeconomic monitoring and research tooling, see [Macro & Financial Markets Terminal](https://github.com/KenaelMartini/macro-financial-markets-terminal).

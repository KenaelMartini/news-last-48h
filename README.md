# Archived News and Market Report Pipeline

This repository contains an earlier working environment used to collect recent financial news, monitor central-bank information, generate market summaries and produce recurring macro and session reports.

It includes source code, configuration files, generated reports, document-formatting utilities, local outputs and build artefacts created during development.

## Technical continuity

This repository was not abandoned without reuse. Parts of its code and workflow were later adapted and integrated into the [Macro & Financial Markets Terminal](https://github.com/KenaelMartini/macro-financial-markets-terminal), particularly for central-bank monitoring and automated reporting.

It therefore represents an earlier development stage of the current terminal project and documents the progression from a standalone experimental workflow toward a broader and more structured application.

## Repository status

This repository is no longer actively maintained as an independent project.

It is kept as an archive of the original research and automation environment. Its structure reflects an experimental development workspace rather than a production-ready application.

Some files, reports, market assumptions and generated outputs are outdated. Build files, temporary outputs and duplicated documents are also retained as part of the historical project state.

For the current implementation and a cleaner presentation of the resulting work, see [Macro & Financial Markets Terminal](https://github.com/KenaelMartini/macro-financial-markets-terminal).
